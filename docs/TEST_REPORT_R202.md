## Assertions
1. Source scene revision / approved master hash and resolved channel visual style are frozen.
2. Every proposal is generated by an explicit local LLM request; neither a queue result nor a GET alters scenes/assets.
3. Output must have exactly the requested indices, no unexpected keys and bounded prompt size.
4. AI cannot instruct automatic import of nonexistent videos; user-edited prompts are not replaced.
5. Stale scene/config revisions prohibit application, with optimistic locking and approved text coverage still enforced.
6. Only registered *active local Ollama* models may execute; no Gemini/Groq/paid call can be dispatched in this task.
7. Queue completion is fenced by the existing lease token; only succeeded result chunks are displayed.
8. Image/AI-video model readiness remains explicitly unverified until separate media preflight.
