# R2-EXT-07/08 — Contracts and maintainability notes

## EXT-07 visual-route preview
`POST /api/videos/:id/visual-route/preview` `{mode:'saving'|'balanced'|'quality', includePaidCandidates?:boolean}`. Produces `{schemaVersion,mode,videoId,compositionDigest,scenes,summary,costEvidence}`. Uses opt-in verified Composition v2 preview, no mutable input source or provider calls. Missing local ComfyUI workflow → recommend user import. Saving mode: verified reuse → user import. Balanced/quality: verified reuse → configured local image recommendation → user import. Quality mode paid clip choice remains `blocked_requires_explicit_approval_and_adapter`, `paidDispatchAllowed:false`, NEVER enqueued. `estimatedNewLocalImageJobs` is only a prospective count, not provider usage. `actualApiUsd:null` means unknown; `estimatedApiUsd:0` is ONLY the read-only preview itself.

## EXT-08 immutable presets and brand kit
`GET /api/motion-style/presets` returns four versioned IDs. `GET /api/videos/:id/motion-style` returns `{revision,style}`. `GET /api/videos/:id/motion-style/revisions/:revision` reads frozen prior style. `POST /api/videos/:id/motion-style/revisions` takes `{expectedRevision, style:{schemaVersion:1,presetId,brand,sceneOverrides}}`. All brand props are whitelisted (short title ≤42 chars; hex colors; caption size 18–42; boolean lower third); no URL/path/font/dynamic code/FFmpeg filter accepted. Per-scene override IDs must belong to current video. Canonical JSON SHA-256 persisted in SQLite v29. Optimistic conflict on old expectedRevision. Prior style revisions cannot be modified/deleted.

## Render binding
`POST /api/videos/:id/renders` retains `{revision,requestKey}` and accepts optional `styleRevision`. Worker rereads an immutable v29 style and verifies digest. It does not mutate the pinned Composition v2 or call any AI. For style-revision render, motion template maps to allowlisted `none`,`zoom`,`pan`,`ken_burns`; transition `cut` or **fade-through-black** (NOT overlapping xfade). Safe brand overlay is generated by drawtext textfile with `expansion=none`; validated palette is injected into ASS subtitle rendering. Original scene frame count, audio and intent/source-fencing remain unchanged. Style digest is combined with Composition digest for distinct private MP4/JPEG files.

`GET /api/videos/:id/renders/:jobId/thumbnail` returns authenticated JPEG after job success and file/size/SHA-256 check. No unauthenticated media URL; UI SDK loads bounded (10MB max) verified JPEG bytes into blob download. R2-EXT-04 MP4 private file is unchanged. Journalled queue remains SP-04.

## Limitations
No provider price verification, actual GPU inference, automatic paid route, remote clip adapter, true crossfade, motion effect editor, user-supplied logo, script style prompt integration, Web Vite build, browser/Windows acceptance or 30–40min benchmark.
